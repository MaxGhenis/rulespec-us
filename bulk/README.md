# Bulk worklist

`worklist.yaml` is retained as non-executable planning data. The former cloud
dispatcher, local drain, raw signing-key path, automatic PR/merge loop, and
progress recipes were removed by the prelaunch canonical-toolchain hard cut.

No entry in this directory can generate, sign, apply, publish, or merge a
RuleSpec module. New atomic encodings remain paused until the named corpus
release, canonical RuleSpec layouts, protected signing supervisor, exact
composer, and Rust engine pins are all active. After that release is explicitly
approved, any replacement bulk lane must invoke the same protected
`axiom-encode encode --apply` transaction and CI contract as an individual
encoding; it must not reintroduce private-key environment variables, ambient
repository discovery, compatibility layouts, or automatic release activation.
